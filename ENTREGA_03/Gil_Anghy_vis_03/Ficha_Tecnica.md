# Ficha Técnica

## Nombre de la base de datos
database_limpia.csv

## Descripción

Base de datos sobre participantes de Miss Universo Chile y sus trayectorias posteriores al certamen.

## Fuente de los datos

Información recopilada mediante revisión de redes sociales, medios de comunicación, entrevistas y registros públicos de las participantes.

## Variables incorporadas

| Variable | Descripción |
| Nombre | Nombre de la participante 
| Año | Año de participación en el certamen 
| Trayectoria posterior | Área profesional o mediática desarrollada posteriormente 

## Procesamiento realizado

Corregimos nuestra base de datos a partir de las correciones de la profesora para poder hacer la visualización correctamente. Posteriormente, se exportó en formato CSV para trabajarla en Python mediante Google Colab y Altair.

## Observaciones

La base permite identificar patrones de permanencia mediática y profesional de las participantes después de su paso por el certamen, evidenciando una fuerte presencia en áreas vinculadas al modelaje y la televisión.
